# Страница публичной оферты

## Цель

Сделать текст публичной оферты доступным по отдельному адресу `https://ocenka-group.ru/oferta/` и открывать эту страницу по ссылке «Публичная оферта» в общем подвале сайта.

## Изменения

- Создать страницу `oferta/index.html`.
- Использовать общие шапку, подвал, шрифты и стили сайта.
- Разместить предоставленный заказчиком текст оферты без смысловых изменений.
- Сохранить заголовки разделов и нумерацию пунктов, чтобы длинный юридический текст было удобно читать.
- Изменить адрес ссылки «Публичная оферта» в `assets/js/site.js` с `/terms/` на `/oferta/`.

## Представление

Страница состоит из заголовка «Публичная оферта на оказание услуг по оценке», даты редакции, вводной части и семи пронумерованных разделов. Контент размещается в центральной колонке с комфортной шириной строки и адаптируется под мобильные экраны.

## Поведение

Нажатие ссылки в подвале выполняет обычный переход на `/oferta/`. JavaScript для открытия модального окна не добавляется.

## Проверка

- Ссылка в общем подвале указывает на `/oferta/`.
- Файл `oferta/index.html` существует и использует абсолютные пути к общим ресурсам.
- Весь предоставленный текст присутствует на странице.
- HTML корректно структурирован заголовками и абзацами.
- На узком экране текст не выходит за границы страницы.

## Границы задачи

Существующая вложенная страница `site_for_mom/terms/index.html` не изменяется. Перенаправления со старого адреса `/terms/` не добавляются.
